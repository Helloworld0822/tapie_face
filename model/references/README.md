# 기준 인물 사진

동의를 받은 기준 인물 사진만 아래 구조로 넣으세요.

```text
references/
  person-a/
    front.jpg
    slight-left.png
  person-b/
    portrait.webp
```

폴더명이 화면에 표시되는 기준 인물 라벨입니다. 앱의 **기준 벡터 다시 만들기**를 누르면 각 사진을
YOLO 얼굴 검출과 5점 정렬, 배경·헤어 마스킹, ArcFace 임베딩 순으로 처리한 뒤 인물별 평균 벡터를
`.data/`에 저장합니다. 원본 사진은 서버 밖으로 전송되지 않지만 생체정보이므로 접근 제어와 당사자
동의가 필요합니다.
